Column Mapping

These CSV column names are recognized and mapped to item fields in the system.

Title→Item Name
Description→Description
Category→Category
LotNumber→Lot Number
Consignor→Consigner Name
ConsignorNumber→Consigner Code
Price→Est. Value (Low)
ReservePrice→Est. Value (High)
Image_1 … Image_N→Photos (URLs)
EventID, Subtitle…→Ignored

Image columns must contain https:// or http:// URLs. Blank image cells are skipped. All other columns are imported as-is; unrecognized columns are ignored.
